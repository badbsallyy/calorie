# Calories - AI-Powered Calorie Tracker

A modern, responsive landing page for an AI-powered calorie tracking application. Built with Next.js 14, React, TypeScript, Tailwind CSS, and Framer Motion.

## Features

- 🎨 **Modern Dark Theme** - Sleek dark design with green accent colors
- ✨ **Smooth Animations** - Powered by Framer Motion for premium feel
- 📱 **Fully Responsive** - Optimized for desktop, tablet, and mobile
- 🚀 **Fast Performance** - Built with Next.js 14 and optimized for speed
- 🎯 **Conversion Optimized** - Hero, Features, Pricing, Testimonials, FAQ, and CTA sections

## Sections

1. **Header** - Sticky navigation with smooth scroll
2. **Hero** - Eye-catching hero with animated phone mockup
3. **Features** - 8 feature cards with icons and animations
4. **How It Works** - 3-step process with animated previews
5. **AI Showcase** - Interactive demo of AI features
6. **Pricing** - 3 pricing tiers with comparison table
7. **Testimonials** - User reviews with ratings
8. **FAQ** - Accordion-style frequently asked questions
9. **Contact** - Contact form with info cards
10. **CTA** - Final call-to-action section
11. **Footer** - Links and app download buttons

## Tech Stack

- **Framework**: Next.js 14 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
- **UI Components**: Custom components inspired by shadcn/ui
- **Icons**: Lucide React

## Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Start production server
npm start
```

Open [http://localhost:3000](http://localhost:3000) to view the application.

## Deploy on Vercel

The easiest way to deploy this app is through [Vercel](https://vercel.com):

1. Push your code to GitHub
2. Import the repository on Vercel
3. Vercel will automatically detect Next.js and deploy
